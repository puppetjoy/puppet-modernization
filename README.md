# Puppet modernization

Puppet modernization development workspace.

## Development and publishing

Canonical development repository (internal access required):
http://gitlab.puppet/puppet/puppet-modernization

Public publishing mirror:
https://github.com/puppetjoy/puppet-modernization

Make development changes through GitLab branches and merge requests.
Do not push directly to GitHub. GitLab pushes protected branches to GitHub
using a repository-specific SSH deploy key; no developer GitHub account
is required. Issues, merge requests, and discussions are not synchronized.

All history reachable from published branches is public. Never commit
secrets or confidential material to published history.
